# Visitas Tupanciretã · IFFar Campus Júlio de Castilhos

Este webapp mostra onde moram os alunos do IFFar Campus Júlio de Castilhos que vivem em Tupanciretã (RS). Com ele, os servidores montam o roteiro de visitas depois do temporal de 20/11/2026.

Para montar um roteiro:
1. Na aba **Alunos**, escolha o curso para ver a lista com nome, turma e endereço de cada aluno.
2. Toque no quadradinho de cada aluno que vai ser visitado.
3. Toque em **Montar roteiro**. O app ordena as paradas a partir da entrada da cidade pela RS-527 e oferece:
   - o link do Google Maps saindo do campus;
   - a versão para imprimir ou salvar em PDF, com o mapa das ruas e a lista de endereços.

O mapa de ruas fica embutido no app e funciona sem sinal.

**Este repositório não contém dados de alunos.** A coordenação manda no grupo dos servidores um link por curso. A lista (nome, curso, endereço e celular) vai dentro do próprio link, depois do `#`, uma parte do endereço que o navegador não envia a nenhum servidor. O colega toca no link e o app abre com a lista, que fica guardada só no celular. Depois disso, o app abre mesmo sem sinal.
